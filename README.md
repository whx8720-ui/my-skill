# 我的技能库

这里备份我在电脑上主动安装和收藏的技能，按实际内容分为两类：

- [`my-skill/`](my-skill/)：我按自己的工作习惯改造或编写的 6 个技能。
- [`other-skill/`](other-skill/)：从网络收藏的 75 个技能。保留原作者文件与资源，版权和许可仍归原作者。

共 **81 个不同技能**。每个技能的用途、电脑上的来源位置，以及写说明时依据的文档，见 [完整清单](SKILLS.md) 或 [CSV 清单](catalog.csv)。优先读取技能目录中的 README；目录无 README 时读取 `SKILL.md`。

`C:/Users/admin/.codex/skills` 中的 `prompt-builder`、`prompt-optimizer`、`product-manager-skills` 与 `D:/skills/other-skill` 对应版本逐文件相同，仓库各保留一份。Cursor 的技能目录是指向 `D:/skills` 的目录联结，也不重复备份。

仓库不包含 WorkBuddy、Codex 系统内置技能、插件缓存和电脑上的其他副本。敏感文件名、依赖目录及超过 50 MB 的文件在复制时排除；详情见 [排除清单](excluded-files.csv)。
