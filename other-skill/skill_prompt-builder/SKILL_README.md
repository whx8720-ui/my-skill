## 🎯 产品概述

提示词巧匠是一款智能提示词构建与优化工具，采用"双阶段"设计范式：

- **阶段一**：提示词优化工具 - 将模糊需求转化为高质量提示词
- **阶段二**：AI内容生成工具 - 基于优化提示词生成最终内容

### 核心特性

- ✅ 支持30个常用AI应用场景
- ✅ 14维度要素框架（角色设定、任务定义、质量要求）
- ✅ 快速模式（3条/10秒）和精准模式（10条/Top3）
- ✅ AI评分排序与学习指导
- ✅ Excel导出功能（详细版/简洁版）
- ✅ 5种目标导向（准确性、一致性、创造性、交互性、效率优先）

## 🚀 快速开始

### 1. 加载Skill

智能体在接收到用户需求后，应**立即加载**本Skill：

```markdown
用户输入："帮我写一篇产品介绍文案"
    ↓
智能体第一反应：调用 prompt-builder Skill ✅
```

### 2. 执行流程

按照SKILL.md中定义的工作流程执行：
1. 场景识别
2. 目标推断
3. 要素框架推荐
4. 一次性收集信息（14个维度）
5. 批量生成提示词（快速/精准模式）
6. AI评分排序
7. 展示Top3提示词
8. 生成学习指导
9. 用户选择：优化 或 生成

### 3. 导出Excel

用户可选择将提示词导出为Excel：

```bash
python scripts/export-to-excel.py \
  --input prompts.json \
  --output prompts_export.xlsx \
  --format detailed
```

## 📖 使用示例

### 示例1：文案撰写

**用户输入**：
> "帮我写一篇智能手表的产品介绍文案"

**智能体执行**：
1. 加载prompt-builder Skill
2. 识别场景：文案撰写
3. 推断目标：创造性优先
4. 推荐要素：身份设定、目标受众、语言风格、内容结构、输出格式等
5. 收集信息：
   - 身份设定：资深营销专家
   - 目标受众：25-35岁年轻白领
   - 语言风格：轻松活泼
   - 内容结构：问题导入→核心观点→论据支撑→行动号召
   - 输出格式：100-200字短文案
6. 生成3条提示词（快速模式）
7. AI评分排序
8. 展示Top3
9. 生成学习指导
10. 用户选择：生成内容
11. AI生成最终内容

## 🔧 技术支持

### 依赖要求

- Python 3.6+
- openpyxl >= 3.0.0

### 安装依赖

```bash
pip install openpyxl
```

### 常见问题

**Q1：提示"缺少 openpyxl 依赖库"怎么办？**
```bash
pip install openpyxl
```

**Q2：智能体没有调用Skill怎么办？**
A：请确保智能体的第一反应是调用prompt-builder Skill，而不是直接使用大模型一般能力。

**Q3：如何导出Excel？**
A：调用 `scripts/export-to-excel.py` 脚本，参见 `references/excel-export-guide.md`。
