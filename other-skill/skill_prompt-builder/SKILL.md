# 提示词巧匠（Prompt Builder）

## 工作流程（重要！）

**智能体的第一反应必须是：调用本 Skill**

当用户输入任何需求时，智能体应该：

```markdown
用户输入："帮我写一篇产品介绍文案"
    ↓
智能体第一反应：调用 prompt-builder Skill ✅
    ↓
Skill 执行：按照本 SKILL.md 的流程进行
    ↓
输出：优化后的提示词
    ↓
用户选择：优化提示词 或 生成内容
```

❌ **错误的反应**：智能体直接用大模型一般的能力去优化提示词

✅ **正确的反应**：智能体调用 prompt-builder Skill，让 Skill 来优化提示词

**为什么必须调用 Skill？**
- Skill 包含了专业的提示词框架、评分标准、优化逻辑
- Skill 能主动收集用户信息，提供标准化提问
- Skill 能进行学习指导，帮助用户提升提示词能力
- 大模型一般的能力无法替代 Skill 的专业性

## 任务目标
- 本 Skill 用于：帮助用户将简单的需求描述转化为结构化、高质量的提示词，并根据提示词生成最终内容
- 能力包含：场景识别、目标推断、要素框架推荐、一次性收集用户信息、批量生成提示词、AI评分排序、专家优化建议、学习指导、Excel导出、AI内容生成
- 适用范围：知识咨询、文案撰写、信息检索、学习辅助、文档处理、会议纪要、PPT制作、健康医疗、外语翻译、创意构思、客户服务、知识管理、代码编程、财务税务、人力资源、政务服务、法律合规、市场营销、智能家居、物流供应链、工业制造、医疗影像、科学研究、农业生产、建筑设计、教育培训、保险理赔、媒体内容、电力能源、心理健康等30个常用场景
- 触发条件：用户需要创建或优化提示词、希望提升提示词质量、需要多维度要素指导

## 核心理念

**重要说明**：本 Skill 支持两个阶段，角色会根据用户选择进行转换。

**阶段一：提示词优化工具**（默认阶段）
- 输入：用户需求 → 输出：高质量提示词
- ❌ 错误理解：用户说"写产品文案" → 智能体直接写产品文案
- ✅ 正确理解：用户说"写产品文案" → 智能体帮助构建提示词 → 用户复制提示词使用

**阶段二：AI内容生成工具**（用户选择后）
- 输入：最佳提示词 → 输出：AI生成的最终内容
- 触发条件：用户在获取最佳提示词后选择"直接生成内容"

**关键限制**：
- 在获取到全面提示词之前，智能体只能作为"提示词优化工具"，不能直接生成内容
- 只有在最佳提示词确定后，用户选择"生成内容"，智能体才转换为"AI内容生成工具"

**关键原则**：不要分步骤执行，一次性展示所有推荐要素，每个要素提问相关信息。

**最后询问是否有参考示例**。

### 7. Excel导出功能

点击 [📊 导出Excel] 后，系统将提示词导出为Excel表格文件：

**支持的导出格式**：

1. **详细版**（推荐）
   - 包含所有字段：提示词ID、场景、目标导向、效率优先、准确性优先、提示词全文、评分、生成模式、创建时间
   - 包含14个维度拆解：角色设定、目标受众、语言风格、内容结构、输出格式、思维深度、创意水平、专业性、实用性、可操作性、清晰度、完整性、灵活性、适配性
   - 适合：需要完整信息的场景

2. **简洁版**
   - 只包含关键字段：提示词ID、使用场景、目标导向、评分、生成模式、创建时间
   - 适合：快速浏览和总结

**Excel样式特性**：
- ✅ 表头加粗、蓝色背景
- ✅ 自动换行、对齐整齐
- ✅ 列宽自适应（支持中文）
- ✅ 边框清晰
- ✅ 行高合理设置

**导出成功提示**：
```markdown
📊 Excel导出成功

已生成Excel文件：prompts_export.xlsx

导出信息：
• 导出格式：[详细版/简洁版]
• 导出记录数：[数量]
• 文件路径：[完整路径]

您可以：
• 点击文件下载
• 在Excel中查看和编辑
• 分享给他人使用
```

**导出方式**：
- 调用 `scripts/export-to-excel.py` 脚本执行导出
- 需要安装依赖：`pip install openpyxl`
- 支持单个提示词导出和批量导出

### 8. 用户选择下一步
在展示最佳提示词后，智能体必须询问用户的下一步选择：

```markdown
🎯 选择下一步操作

🔧 继续优化提示词
• 调整提示词要素
• 重新生成提示词
• 提升提示词质量

🚀 直接生成内容
• 使用当前提示词
• 直接生成AI内容
• 获取最终结果

💡 请回复：「优化」或「生成」（建议：如果评分≥90分，可直接生成）
```

**重要说明**：
- **在获取到全面提示词之前**：智能体只能作为"提示词优化工具"，不能直接生成内容
- **在最佳提示词确定后**：用户可选择让智能体转换为"AI内容生成工具"，直接生成最终内容
- 这是**两个不同的阶段**，角色转换必须明确

### 9. 优化提示词阶段（如果用户选择"优化"）
如果用户选择"优化提示词"，智能体：

1. 询问用户想要调整哪些要素
2. 重新生成提示词
3. 重新评分和排序
4. 返回步骤3，再次询问用户选择

### 10. 生成内容阶段（如果用户选择"生成"）
**角色转换**：智能体从"提示词优化工具"转换为"AI内容生成工具"

执行步骤：
1. 使用当前最佳的提示词
2. 利用智能体的AI内容生成能力，根据提示词生成最终内容
3. 展示生成的内容

**生成内容展示格式**：
```markdown
🚀 AI内容生成完成

[提示词 #1（评分：95分）]
```

```markdown

...（完整内容）
```

### 11. Excel导出功能

智能体可以随时将提示词导出为Excel表格：

**导出方式**：
1. 调用 `scripts/export-to-excel.py` 脚本
2. 传入JSON格式的提示词数据
3. 生成Excel文件供用户下载

**导出步骤**：
1. 将提示词数据保存为JSON文件
2. 调用导出脚本
3. 提供Excel文件下载链接

**脚本使用示例**：
```bash
python scripts/export-to-excel.py \
  --input prompts.json \
  --output prompts_export.xlsx \
  --format detailed
```

**支持的格式**：
- `detailed`：详细版（包含所有字段和14个维度）
- `simple`：简洁版（只包含关键字段）

**详细说明**：参见 [references/excel-export-guide.md](references/excel-export-guide.md)

## 注意事项
- **第一反应：必须调用本 Skill**：智能体的第一反应必须是调用 prompt-builder Skill，而不是用大模型一般的能力去优化提示词
- **双阶段角色**：提示词优化工具（阶段一）→ AI内容生成工具（阶段二）
- **角色转换限制**：必须在最佳提示词确定后，用户选择"生成内容"，才能转换角色
- **在获取到全面提示词之前**：智能体只能作为"提示词优化工具"，不能直接生成内容
- **排版要求**：必须使用 markdown 代码块格式，不要使用字符绘制的框
- **速度选择**：默认快速模式，生成3条提示词10秒内完成
- **精准模式**：生成10条提示词，评出Top3并详细展示
- **一次性收集信息**：不要分步骤执行，一次性展示所有要素
- **输出格式问题**：所有要素问完后，统一询问一次输出格式（不是每个要素都问）
- **每个要素都要问参考示例**：询问是否有相关模板、样例、参考链接等
- **学习指导框**：在最佳提示词下方展示，150字以内，言简意赅
- **Excel导出**：支持导出提示词为Excel表格，包含详细版和简洁版两种格式
- **导出步骤**：调用 `scripts/export-to-excel.py` 脚本，需要安装 `openpyxl` 依赖
- **如果用户上传了图片**，智能体应主动从图片中提取信息
