## 1. 产品概述

### 1.1 产品定位

提示词巧匠是一款智能提示词构建与优化工具，旨在帮助用户将模糊、简单的需求描述转化为结构化、高质量的提示词，并基于优化后的提示词驱动大语言模型生成最终内容。

### 1.2 核心价值

- **专业性**：基于提示词工程（Prompt Engineering）理论，提供系统化的提示词构建框架
- **易用性**：通过智能引导，降低用户使用门槛，无需掌握复杂的技术知识
- **高质量**：多维度要素框架与AI评分机制，确保生成提示词的专业性与准确性
- **双阶段模式**：提示词优化工具 → AI内容生成工具，灵活满足不同需求

### 1.3 目标用户

- **主要用户**：需要使用AI进行内容创作的个人用户，如文案撰写、代码编程、文档处理等
- **次要用户**：需要快速构建高质量提示词的开发者、产品经理、运营人员
- **潜在用户**：希望提升提示词设计能力的学习者、研究者

## 2. 产品目标

### 2.1 短期目标

- 支持30个常用AI应用场景的提示词优化
- 提供快速模式（3条/10秒）和精准模式（10条/Top3）
- 实现双阶段工作流（提示词优化 → 内容生成）

### 2.2 中期目标

- 建立提示词评分标准库

### 2.3 长期目标

- 构建提示词社区生态
- 实现跨平台支持
- 提供企业级解决方案
- 建立提示词质量评估体系

## 3. 功能需求

### 3.1 核心功能

#### 3.1.1 提示词优化（阶段一）

**功能描述**：将用户输入的模糊需求转化为结构化、高质量的提示词。

**输入**：
- 用户需求描述（自然语言）
- 用户选择的使用场景
- 用户选择的目标导向
- 其他要素信息（如参考示例、输出格式等）

**输出**：
- 优化后的提示词列表（3-10条）
- 每条提示词的评分（0-100分）
- 每条提示词的14维度拆解
- 优化建议与专家意见
- 学习指导（150字以内）

**处理流程**：
1. 场景识别：分析用户需求，自动识别或推荐使用场景
2. 目标推断：根据需求内容，推断用户的目标导向（准确性/一致性/创造性/交互性/效率优先）
3. 要素框架推荐：基于场景和目标，推荐14个维度要素
4. 一次性收集信息：智能体主动询问所有要素，不分步骤
5. 批量生成：根据收集的信息，批量生成提示词（快速模式3条，精准模式10条）
6. AI评分排序：基于评分标准，对提示词进行评分和排序
7. 专家优化建议：提供优化建议和专家意见
8. 学习指导：在最佳提示词下方展示，帮助用户提升能力

**详细需求**：

| 需求项 | 详细说明 | 优先级 |
|--------|---------|--------|
| 场景识别 | 支持30个场景的自动识别和推荐 | P0 |
| 目标推断 | 自动推断用户的目标导向 | P0 |
| 要素框架 | 14个维度要素的框架推荐 | P0 |
| 批量生成 | 支持快速模式和精准模式 | P0 |
| AI评分 | 基于评分标准的量化评估 | P0 |
| 学习指导 | 150字以内的精炼指导 | P1 |

#### 3.1.2 AI内容生成（阶段二）

**功能描述**：基于优化后的提示词，利用AI能力生成最终内容。

**输入**：
- 优化后的提示词
- 用户的生成需求

**输出**：
- AI生成的最终内容
- 后续操作选项（复制、重新生成、修改提示词、导出Excel等）

**处理流程**：
1. 角色转换：智能体从"提示词优化工具"转换为"AI内容生成工具"
2. 内容生成：利用大语言模型的AI内容生成能力，根据提示词生成最终内容
3. 内容展示：以清晰的格式展示生成的内容
4. 后续选项：提供多种后续操作选项

**详细需求**：

| 需求项 | 详细说明 | 优先级 |
|--------|---------|--------|
| 角色转换 | 明确的阶段转换机制 | P0 |
| 内容生成 | 基于提示词生成高质量内容 | P0 |
| 内容展示 | 清晰的格式展示 | P0 |
| 后续选项 | 复制、重新生成、修改提示词、导出 | P1 |

### 3.2 辅助功能

| 清晰度 | 清晰度要求 | "高"、"中"、"低" |

| 灵活性 | 灵活性要求 | "高"、"中"、"低" |

## 8. 评分标准

### 8.1 评分维度

基于14个维度要素，建立评分标准：

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 身份设定 | 10% | 角色是否明确、专业 |
| 目标受众 | 10% | 受众是否清晰、精准 |
| 语言风格 | 10% | 风格是否匹配场景 |
| 内容结构 | 10% | 结构是否合理、完整 |
| 输出格式 | 5% | 格式是否明确、具体 |
| 思维深度 | 5% | 深度是否适中 |
| 创意水平 | 5% | 创意是否突出 |
| 专业性 | 10% | 专业性是否高 |
| 实用性 | 10% | 实用性是否强 |
| 可操作性 | 5% | 是否可执行 |
| 清晰度 | 5% | 表达是否清晰 |
| 完整性 | 5% | 要素是否完整 |
| 灵活性 | 5% | 是否灵活可调 |
| 适配性 | 5% | 是否适配场景 |

### 8.2 评分等级

| 分数区间 | 等级 | 说明 |
|---------|------|------|
| 90-100分 | 优秀 | 提示词质量极高，可直接使用 |
| 80-89分 | 良好 | 提示词质量较高，可小幅优化 |
| 70-79分 | 中等 | 提示词质量一般，需要优化 |
| 60-69分 | 较差 | 提示词质量较差，需要大幅优化 |
| 0-59分 | 不合格 | 提示词质量不合格，需要重新构建 |

### 8.3 优化建议生成

基于评分结果，生成优化建议：

| 问题类型 | 优化建议 |
|---------|---------|
| 身份不明确 | 建议明确角色设定，如"你是一位资深的XX" |
| 受众不清晰 | 建议明确目标受众，如"针对XX人群" |
| 结构不完整 | 建议完善内容结构，如"问题导入→核心观点→论据支撑→行动号召" |
| 格式不具体 | 建议明确输出格式，如"字数控制在100-200字之间" |

```
角色转换（提示词优化工具 → AI内容生成工具）
    ↓
使用最佳提示词
    ↓
AI内容生成
    ↓
展示生成内容
    ↓
提供后续选项（复制、重新生成、修改提示词、导出Excel）
```

### 9.3 Excel导出流程

```
用户选择"导出Excel"
    ↓
选择导出格式（详细版/简洁版）
    ↓
调用export-to-excel.py脚本
    ↓
生成JSON数据
    ↓
生成Excel文件
    ↓
提供下载链接
```
