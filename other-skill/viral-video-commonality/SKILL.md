# 短视频爆款共性分析框架

## 核心公理

> 一条短视频，本质是「一个用户在时间轴上做出一系列是否继续观看的决策」。
>
> 爆款的共性，必然体现在影响这些决策的三层机制上：
> **触发（为什么点进来）→ 留存（为什么看下去）→ 转化（为什么有反应）**

批量分析的任务：在同一层机制里，找到多条视频的共同答案。

---

## 七个分析维度

### 触发层 — 决定点击率

#### 维度① 钩子类型（前3秒）

分析前3秒用了什么手段留住用户。从以下类型中识别：

| 钩子类型 | 特征描述 | 示例 |
|---|---|---|
| 身份认同型 | 直接点名目标群体 | "有孩子的家长注意了" |
| 提问悬念型 | 抛出一个让人想知道答案的问题 | "你知道为什么他们总是做错吗？" |
| 冲突画面型 | 开场即呈现强烈的视觉/情绪冲突 | 争吵、崩溃、反差场景 |
| 数字冲击型 | 用具体数字制造反差感 | "95%的人都做错了这件事" |
| 反常识型 | 颠覆日常认知 | "你以为的爱，其实是伤害" |
| 故事带入型 | 直接进入一个正在发生的故事 | "那天他突然发了一条消息..." |

**批量比较问题**：这批视频中，哪种钩子类型出现频率最高？

---

#### 维度② 标题公式

分析标题的句式结构类型：

| 公式类型 | 句式特征 | 示例 |
|---|---|---|
| 场景触发型 | 「当XXX时」「如果你XXX」 | "当孩子崩溃时，父母的教科书级安抚" |
| 数字清单型 | 「X个XXX」「X种XXX」 | "5个让你效率翻倍的方法" |
| 身份对话型 | 直接称呼目标受众 | "所有在外漂泊的孩子，看完请转给父母" |
| 反问冲突型 | 「为什么XXX」「你真的XXX吗」 | "你以为的孝顺，其实是在伤害父母" |
| 结果承诺型 | 「XXX天/分钟学会XXX」 | "3分钟学会这个，从此不再XXX" |

**批量比较问题**：这批视频最常用哪种标题公式？组合方式是什么？

---

### 留存层 — 决定完播率

#### 维度③ 叙事结构

识别整体内容的组织框架：

| 结构模板 | 时间轴描述 | 常见于 |
|---|---|---|
| 问题→解决 | 提出痛点 → 分析原因 → 给出方法 | 干货教程、方法论类 |
| 冲突→反转→升华 | 建立预期 → 打破预期 → 情感升华 | 情感类、故事类 |
| 故事→结论 | 讲一个具体事件 → 提炼观点 | 案例分享、观点输出 |
| 观点→论证→行动 | 抛出核心观点 → 多角度论证 → 呼吁行动 | 观点输出、价值观类 |
| Before→After | 呈现改变前的状态 → 呈现改变后的状态 | 变化展示、对比类 |
| 列举式 | 第1点...第2点...第3点... | 清单类、干货类 |

**批量比较问题**：这批视频最多使用哪种结构？是否有共同的变体？

---

#### 维度④ 情绪弧线

分析情绪在时间轴上的分布：

**核心情绪类型**（识别主打哪一种）：
- 愧疚感：「我是不是做错了」
- 焦虑感：「我会不会失去/错过什么」
- 共鸣感：「这说的就是我」
- 优越感：「我比别人懂得更多」
- 好奇心：「我不知道，我想知道」
- 温暖感：「这让我感到被理解/被爱」
- 愤怒感：「这不对，我要评论」

**情绪高点分析**：
- 情绪峰值出现在视频的哪个时间段（前1/3、中段、结尾）
- 用什么手段触发（特定台词/画面切换/音乐变化/停顿）

**批量比较问题**：这批视频的主导情绪是什么？情绪高点集中在哪个时间区间？

---

#### 维度⑤ 信息节奏

分析内容密度和节奏模式：

| 节奏类型 | 特征 |
|---|---|
| 快切密集型 | 每3-5秒一个画面切换，信息点密集，语速快 |
| 慢叙留白型 | 单个画面时间长，语速慢，情绪空间大 |
| 前快后慢型 | 开头快节奏抓注意力，中后段放慢深化情感 |
| 渐进加速型 | 越到后面节奏越快，制造情绪加速感 |

**信息密度**：每10秒平均传递几个独立信息点（1-2个为稀疏，3-4个为中等，5个以上为密集）

**批量比较问题**：这批视频的节奏模式是否一致？信息密度范围是多少？

---

### 转化层 — 决定互动/分享率

#### 维度⑥ 结尾设计（最后10-15秒）

| 结尾类型 | 手段描述 | 目标行为 |
|---|---|---|
| 提问引评论 | 在结尾抛出一个开放性问题 | 评论 |
| 身份认同收尾 | 「你也是这样吗」「转给需要的人」 | 转发/收藏 |
| 悬念留白 | 故意不给完整答案，暗示下期 | 关注 |
| 价值承诺CTA | 明确告诉用户做了什么动作能得到什么 | 点赞/收藏 |
| 情感共鸣收尾 | 以一句话总结核心情感，触发共鸣点 | 转发/点赞 |

**批量比较问题**：这批视频最多用哪种结尾？与核心情绪是否形成配套？

---

#### 维度⑦ 核心情绪（见维度④）

核心情绪同时决定了转化行为的类型：
- 愤怒/不满 → 评论
- 共鸣/感动 → 转发
- 干货/价值 → 收藏
- 好奇/悬念 → 关注

---

## 执行步骤

### 输入要求

- 视频数量：建议 5-20 条（太少规律不稳定，太多信息过载）
- 视频来源：同一关键词/话题下的爆款，或竞品账号的高播放作品
- 分析目标：明确是「找内容模板」还是「找情绪机制」还是「找结构规律」

### 步骤1：逐条标注

对每条视频，用以下标签填表：

```
视频编号: V01
钩子类型: [从维度①选一个]
标题公式: [从维度②选一个]
叙事结构: [从维度③选一个]
核心情绪: [从维度④选一个]
情绪高点时间: [xx秒-xx秒]
信息节奏: [从维度⑤选一个]
信息密度: [每10秒x个信息点]
结尾类型: [从维度⑥选一个]
```

### 步骤2：统计共性

对每个维度做频率统计，找出「超过60%的视频选了同一选项」的维度——这就是该话题的**硬共性**。

### 步骤3：输出可复刻模板

将所有硬共性拼成一个模板：

```
【话题XXX 爆款模板】

标题公式：[最高频公式]
前3秒：[最高频钩子类型] + 具体手段
结构框架：[最高频叙事结构]
主打情绪：[核心情绪] → 情绪高点在[时间区间]
信息节奏：[节奏类型]，每10秒[x]个信息点
结尾：[最高频结尾类型]

可复刻句式：[从原视频中提取最高频的句式模板]
```

### 步骤4：反常识检查

找到**不符合共性但同样爆款**的视频，分析它「靠什么弥补了」——这些是高阶变体，可以作为创新方向。


## 边界（什么时候不适用）

- **视频数量少于3条**：无法找到规律，建议先做单条深度分析
- **话题跨度太大**：「情感类」和「干货教程类」混在一起分析，共性没有意义，需要先按话题拆分
- **纯数据分析需求**：本框架分析的是内容机制，不分析播放量/完播率等数据指标——两者需要结合使用
- **创意突破需求**：共性分析帮你「复刻均值」，但如果目标是「做出差异化爆款」，需要反过来用——找共性是为了找到可以打破的地方
