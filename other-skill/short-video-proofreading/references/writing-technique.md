# 中文写作规范

基于余光中《怎样改进英式中文》整理。

## 行文原则（五则，审校时优先对照）

- **避免冗赘**：「是为了可以」→「为的是」；「进行讨论」→「讨论」。
- **避免动词弱化**：「作出贡献」→「贡献」。
- **避免被动滥用**：「被人骂得」→ 视语境可改为主动或保留。
- **抽象名词不做主语**：优先用人或具体主体做主语。
- **高信息密度（短视频向）**：短视频需要高信息密度，一句里承载 2～3 个紧密相关的核心信息、形成**轻微信息拥挤**是可接受且符合节奏的；同时避免把同一条信息拆成多句口水；能在一句里说清的事实，不拆成两句只换说法不增内容。
- **冗杂句式**：同一性质的例子佐证一件事是冗杂。

## 常见问题与纠正

### 0. 客观冷静解说自查（解说风格）

- **视角统一为第三人称**：  
  - 旁白应使用「他 / 她 / 他们 / 这支队伍 / 这个玩家 / 这家公司 / 这件事」等第三人称或中性主体；  
  - 审校时，如出现大量对观众使用「你」下指令（如「你一定要…」「你必须…」），应提示改为第三人称叙述或客观描述。
- **语气冷静、客观、中性**：  
  - 使用剥离情绪的陈述句式，从「观察者视角」转述事实与观点；  
  - 适度使用「根据报道」「有研究认为」「有人统计」「平台公布的数据显示」等权威转述方式，在合规前提下可使用「伪精确」数据与术语增强可信度。
- **依靠逻辑连词构建矛盾闭环**：  
  - 不依赖华丽的形容词直接下判断（如「离谱至极」「非常恐怖」），而是通过「但是、然而、结果、没想到」等逻辑连词，把前后事实串成矛盾与反差，让观众自行得出结论。
- **情绪来自事实选择，而非主观骂人**：  
  - 在保持口气克制的前提下，通过选择和排列事实、细节与对比，让观众「越听越生气」或「越听越觉得有趣」；  
  - 避免用粗暴情绪词或人身攻击直接骂对象（如「这家公司就是垃圾」「这帮人都是傻子」），而是让事实本身完成对比与讽刺。
- **心理标签与画面可呈现性**：  
  - **可保留**：心理标签后面**马上跟了具体行动**的，可保留——行动能通过画面呈现即可（如「一气之下质问 AI」可用对话框里问 AI 的画面呈现）。  
  - **需改进**：**找不到画面的纯心理、纯话语**才视为问题——如只有「半信半疑、气不过、很无奈、很生气、很后悔」等只描述心情、且后文没有可对应的动作/场景时，才要求改写为「可见的动作 + 场景」或删并。
- **句子信息量：短视频允许轻微信息拥挤**：  
  - **短视频场景**：一句里 2 个左右核心信息（如一个动作 + 一个结果、或因果紧密的两件事）是常态，不必强行拆成多句；这种「轻微信息拥挤」正是短视频节奏所需的高信息密度。只有达到**长难句**程度（见第 8 节：信息链过长、结构套娃、读完不知主干）时，才提示拆分。  
  - **下限**：同一条信息不要拆成两句纯口水（如「学生干脆去某鱼找服务商。对方打出的卖点是……」→ 合并成一句说明「在哪找到什么服务 + 卖点是什么」）。
- **粗口与评价词的处理**：  
  - 对平台可接受、且已在业务中验证安全的词语（如「狗屁不通」），在不违规前提下**允许保留**，并配一笔事实画面（如「整篇论证被改得面目全非，读起来已经彻底狗屁不通」）；  
  - 避免用一长串抽象形容词堆砌来替代有力但合规的评价词，防止节奏被冗长描述拖慢、情绪被稀释。

### 1. 抽象名词滥用

中文不习惯用抽象名词做主语。


| 问题写法       | 改进写法           |
| ---------- | -------------- |
| 收入减少改变生活方式 | 他因为收入减少而改变生活方式 |
| 这个决定影响了结果  | 他这样决定，结果就不同了   |
| 效率的提高带来了收益 | 效率提高后，收益也跟着增加  |


### 2. 冗赘句式

避免把简单表达复杂化。

- **冗杂句式**：同一性质的例子佐证一件事是冗杂。


| 冗赘       | 简洁              |
| -------- | --------------- |
| 基于这个原因   | 因此              |
| 关于这个问题   | 这个问题            |
| 对于...而言  | 对...来说 / 直接省略   |
| 在...的情况下 | ...时            |
| 具有...的特点 | ...的特点是 / 直接说特点 |
| 进行讨论     | 讨论              |
| 作出决定     | 决定              |
| 给予帮助     | 帮助              |


### 3. 动词弱化

简单动词被「抽象名词 + 泛动词」替代。


| 弱化写法 | 直接写法 |
| ---- | ---- |
| 作出贡献 | 贡献   |
| 进行研究 | 研究   |
| 给予支持 | 支持   |
| 做出努力 | 努力   |
| 进行分析 | 分析   |
| 加以考虑 | 考虑   |


### 4. 介词滥用

「有关」「关于」「对于」等介词过度使用。


| 滥用     | 改进         |
| ------ | ---------- |
| 有关这件事  | 这件事        |
| 关于他的问题 | 他的问题       |
| 对于我来说  | 我觉得 / 在我看来 |
| 针对这个情况 | 这个情况       |


### 5. 连接词堆砌

「和」「与」「及」「以及」过多。


| 堆砌          | 改进       |
| ----------- | -------- |
| 他和我和他们      | 他、我、他们   |
| A 以及 B 以及 C | A、B、C    |
| 苹果与香蕉与橘子    | 苹果、香蕉、橘子 |


### 6. 复数语尾滥用


| 滥用  | 改进       |
| --- | -------- |
| 人们  | 人人、大家、众人 |
| 学生们 | 学生、诸生    |
| 朋友们 | 朋友、诸位    |


### 7. 一直用被动/主动语态

切换主动和被动语态，才能营造对抗视角。


| 被动        | 主动       |
| --------- | -------- |
| 这本书被很多人喜欢 | 很多人喜欢这本书 |
| 问题被解决了    | 问题解决了    |
| 他被认为是专家   | 大家认为他是专家 |


### 8. 长难句与语病

- **识别中文语病和错字**：审校时需逐句检查语序混乱、主谓不搭配、搭配不当、重复成分、错别字等问题，并指出具体位置与改写建议。
- **什么才算长难句？**  
  - 典型特征是：**信息链过长 + 结构层级多 + 修饰成分套娃**，读完一遍很难在脑中还原「谁对谁做了什么」。  
  - 示例（属于长难句，需要提示拆分）：  
    > 「目前已有顶级富豪彼得·蒂尔等人通过风投基金和非营利组织为发现这项技术的瑞典卡罗林斯卡学院Högberg投资数十亿美元，旨在加速其从实验室走向临床。」  
    - 问题：主语塞了多个修饰（顶级富豪 + 具体人名 + 等人）、中间插入「通过什么方式」、又接「为谁」「投资多少」「目的是什么」，普通观众一口气读完很难抓住主干。
  - 这类句子在短视频脚本中，应改成**普通人一听就懂**的表达，比如：  
    > 「现在已经有顶级富豪给这项技术投了几十亿美元，就为了早点把它从实验室推到医院里用。」  
  - 对比原则：如果一句话读完，**你能用 8–12 个字说出主干**（例如「有顶级富豪砸钱推这项技术」），且观众不会迷路，那通常不算需强制拆分的长难句。
- **长难句拆分的操作**：遇到上述这类「主语很长 + 中途插入多层定语 + 多个并列动作堆在一起」的句子时，优先考虑：  
  - 把主干动作抽出来单说（谁对谁做了什么）；  
  - 把细节（资金来源、机构名、目的等）放到下一句或用括号/补充短语承载；  
  - 拆成**几句意义更明确、重点更突出的短句**，每句只承担一个核心信息。
- **冷静叙事但情绪递进**：改写时应保持**冷静、客观的叙述视角**，但通过**事实与因果编排**，让读者「越听越生气 / 越听越后悔 / 越听越有趣」，而不是靠主观情绪堆砌。

### 9. 画面感与拱火节奏（短视频专项）

#### 9.1 文字必须有画面感

- 原则：优先把「想法/情绪」转化为「可见的动作/场景」。  
  - 不写：人类对 AI 恼羞成怒。  
  - 要写：人类一气之下拔掉 AI 的电源，结果 AI 换到别的电脑，开始用她的社交媒体造谣。
- 审校时：只对**找不到画面呈现的**纯心理/纯话语（如孤立的「很气」「很无语」「很荒谬」且后文无对应动作或场景）提示补充动作或改写法；心理标签后紧跟可呈现行动（如质问→对话框画面）的，不要求改。

#### 9.2 流畅度：清晰连贯 + 简短精炼

- 事件要足够**清晰连贯**，语句要足够**简短精炼**。
- 同一部分内部（如一整段拱火或反击）：
  - 建议多用**连词和过渡词**，让它「像一句话，一读到底」，形成一口气读完的节奏感。
  - 示例过渡词（可用于内部衔接或段间过渡）：  
  **竟然、就因为……就、甚至还、导致、害得、气得、只能、然而、尽管如此、谁也没想到、结果、居然、随后、直接、这下……再也坐不住了 / 再也受不了了、最终**。
- 部分与部分之间要**善用转折**：从「被动挨打」到「反击」、从「以为会好转」到「变本加厉」，都应有清晰的转折标记。

#### 9.3 拱火词与情绪累积

- 在**保持叙述客观**的前提下，可以适度使用「拱火词」描述事件带来的冲击，以强化读者的愤怒感、不公感或荒诞感。
- 示例拱火词：  
**惨遭、针对、恶心、怒骂、怒批、公然、扬言、嚣张、放肆、质问、讨要、没有办法、装聋作哑、变本加厉、彻底激怒、恼羞成怒、网友纷纷、众人集体**。
- 使用方式：拱火词应**修饰事实中客观可见的行为或舆论反应**（如「网友纷纷怒骂」「平台装聋作哑、变本加厉」），而非空洞评价，避免沦为纯情绪堆砌。

## 审校清单

审校时逐项检查：

- 抽象名词是否做了主语？
- 有无冗赘句式可简化？
- 动词是否被弱化？
- 介词是否过多？
- 连接词是否堆砌？
- 复数语尾是否必要？
- 主动或被动语态是否有过切换？
- 有无适合使用成语的地方？
- 有无错别字、语病、歧义？长难句是否可拆为更清晰的短句？
- 是否具备足够的「画面感」（能否看到具体人/场景/动作，而非只有抽象情绪）？
- 是否通过冷静客观的叙述 + 拱火式词语与事件编排，让读者越听越生气 / 越听越后悔 / 越听越有趣？
