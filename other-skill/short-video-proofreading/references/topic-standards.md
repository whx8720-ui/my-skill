# 选题标准与及格判定

选题需**先做前置判定与选题合规检查**，再通过五维检查；**全部通过**后才进入后续优化。任一项不及格则输出对应理由，不进入优化流程。审校时在**步骤 1：选题检查**中使用。

---

## 前置判定：专业长分析观点类直接 Pass

**在五维检查之前**，先判断文案是否属于以下类型：

**类型**：**财经、医疗、科技、生物** 领域中，**专业的长分析、观点输出类**文案。

**判定要点**：

- **领域**：内容以财经（如宏观/策略/研报解读）、医疗（如病症/用药/诊疗建议）、科技（如技术原理/产业分析）、生物（如生命科学/实验结论）等**专业向**为主；
- **形式**：**长分析**——多段论证、数据/研报引用、逻辑推演为主；
- **性质**：**观点输出**——以给出专业判断、预测、建议为核心，而非以具体事件/人物/冲突为主线的**故事化叙事**。

**若同时满足「上述领域 + 长分析 + 观点输出」**：选题**直接 pass**，不进入五维检查，不进入后续优化。

### 直接 Pass 时的理由与输出

- **理由**：「选题属于 [财经/医疗/科技/生物] 领域专业长分析观点输出类文案，不符合本审校流程的选题范围，直接 pass。」
- **建议**：若需做此类内容，请使用对应领域的专业审校或合规流程；本流程适用于故事化、事件向、可复述名场面的短视频选题。

---

## 一、爆点（必选维度）

**核心三角**：**利益**、**共鸣**、**反直觉**。爆点需至少扣住其一，且能用一句话说清。

**定义**：至少具备一个清晰爆点——**反转**或**新奇**（吸引注意），并尽量往**极端化 / 违直觉 / 低门槛共鸣**靠拢（转发动力）。

---

### 1. 利益 / 情绪的「极端化」

- **作用**：反转和新奇负责**吸引注意**，**极端**才是**转发动力**。
- **要求**：利益或情绪被推到极端结果（赚/赔、赢/输、安全/危险等反差极大），让人有「这也太离谱了」的冲击感。
- **示例**：小聪明反而输光、省小钱赔大钱、一次选择改变命运等。

### 2. 认知「违直觉」(Counter-intuitive)

- **定位**：「新奇」的进阶版——不仅是少见，而是**挑战常识**。
- **核心**：告诉观众——**他以为对的事情，其实全错了**；制造「我得赶紧看看我有没有犯错」的紧迫感。
- **爆点示例**：「为了省钱买打折菜，结果让他赔掉了一套房。」（常识：省钱是对的 → 违直觉：在这种情境下省钱反而酿成大祸）
- **及格倾向**：选题能提炼出一句「大家常以为 X，其实 Y」的违直觉结论。

### 3. 低门槛的「强共鸣」

- **问题**：新奇点太高冷（如量子物理新发现），大众带不动，难以传播。
- **要求**：爆点必须**降维**到大众日常：**衣食住行、搞钱、两性、职场**。
- **爆点逻辑**：越是**琐碎的生活场景**里发生**巨大的反转**，传播力越强。
- **及格倾向**：普通人一听就懂、一想就「我也有过/我差点也这样」的场域。

---

### 及格标准


| 维度                      | 要求                                                 |
| ----------------------- | -------------------------------------------------- |
| **反转 / 新奇**             | 存在「预期 vs 结果」冲突或少见操作，能 3 秒内抓住注意                     |
| **可概括**                 | 能用一句话说明爆点（建议含利益/共鸣/反直觉之一）                          |
| **极端 / 违直觉 / 共鸣（至少其一）** | 利益或情绪有极端化；或具备「以为对其实错」的违直觉；或落在衣食住行/搞钱/两性/职场等低门槛共鸣场域 |


### 不及格理由（输出时照用或微调）

- **缺少爆点**：「选题缺少明确爆点，未体现反转或新奇，难以在 3 秒内说清为什么要看这条。」
- **爆点模糊**：「爆点表述不清，无法用一句话概括，不利于开头钩子设计。」
- **爆点不高**：「爆点仅停留在吸引注意，缺乏极端化/违直觉/低门槛共鸣，转发动力不足。」
- **共鸣门槛高**：「新奇点过于高冷，未降维到衣食住行、搞钱、两性、职场等大众场域，传播力有限。」

---

## 二、受众范围

**定义**：受众越广越好；若为具体游戏/垂类（如终末地、原神），需能拉出对大众可共鸣的映射。

### 及格标准


| 类型       | 要求                                                    |
| -------- | ----------------------------------------------------- |
| **泛受众**  | 话题人人能懂、能共鸣：钱、情感、规则被玩坏、生存焦虑、社会争议等                      |
| **垂类受众** | 明确指向某圈层（如某游戏玩家），且：在圈内极有争议/爆点，或能拉出对大众有意义的对照（氪金、沉迷、规则等） |


### 不及格理由

- **受众过窄**：「选题过于垂直，仅少数玩家/粉丝能懂，且未拉出对大众可共鸣的问题（钱/规则/生存/情感），受众范围不足。」
- **受众模糊**：「目标受众不清晰，既非泛受众也非可运营垂类，难以判断流量池。」

---

## 三、主体（谁在经历/做这件事）

**定义**：事件中的「谁」。主体要么**足够典型**，要么**足够特殊**，要么**主体冲突有看点**，最好一眼就知道「跟我有什么关系」。

### 及格标准


| 类型            | 要求                                                    |
| ------------- | ----------------------------------------------------- |
| **典型人群**      | 大学生、社畜、中年人、全职妈妈、普通网友等，易代入                             |
| **特殊身份**      | 科技博主、游戏大神、名人、官方机构等，自带关注度                              |
| **模拟类/符号化主体** | 非人类角色（如蚂蚁、AI、虚拟小人、火柴人），作为博弈/实验中的「谁」；观众通过映射理解「跟我有什么关系」 |
| **主体与事件**     | 主体与事件之间有张力（如科技博主被 AI 反杀、大学生用 AI 还贷）                   |


### 主体冲突有看点

- **对立不产生于「身份组合」**，而产生于**「利益/规则的结构性错位」**。
- 例：学生 vs 导师——仅身份组合，未必有看点；**黑粉 vs 王力宏机器人**——评价权、立场、规则错位，有对立。
- 及格倾向：主体之间因利益争夺、规则对抗、评价权冲突等形成可感知的对立，而非单纯身份标签堆砌。

### 不及格理由

- **主体模糊**：「主体不明确或难以代入，观众无法建立‘谁在经历什么’的认知。」
- **主体与事件脱节**：「主体身份与事件类型不匹配，缺乏张力，难以引发兴趣。」
- **主体冲突无看点**：「主体之间仅有身份组合，无利益/规则的结构性错位，对立感不足。」

---

## 四、事件类型（故事骨架）

**定义**：事件属于易引发讨论的类型，具备起因–经过–结果，而非流水账或心情随笔。

### 及格类型（至少符合其一）


| 类型             | 说明                               |
| -------------- | -------------------------------- |
| **撕逼/冲突**      | 人 vs 人、人 vs 平台、人 vs 规则，有明确对抗     |
| **整活/实验**      | 用 AI/规则/游戏做极限实验，玩出新结果            |
| **正能量/反转救赎**   | 从失败、误解、偏见走向释怀、和解或成长              |
| **科技突破/规则被玩坏** | 新技术、新机制、新 bug，挑战既有认知             |
| **猎奇**         | 少见、反常、极限操作、「居然还能这样」，满足好奇与窥探欲     |
| **焦虑**         | 围绕生存、职场、钱、未来等压力展开的事件与后果          |
| **信息差**        | 我知道你不知道、内行外行差、先知道的人占优，制造「得赶紧补课」感 |
| **嘴替**         | 替某一群体说出不敢说/说不清的观点，代表他们发声、怼人或吐槽   |


### 及格标准

- 能明确归入上述至少一类；
- 具备完整「事」：有起因、经过、结果，可复述。

### 不及格理由

- **事件类型不清**：「事件类型不清晰，更像日常吐槽或感想，缺乏可复述的完整事件，难以支撑一条短视频。」
- **无事件骨架**：「仅有观点或情绪，没有具体事件（谁在什么情境下做了什么、结果如何），无法形成故事。」

---

## 五、情绪基调

**定义**：主打情绪明确，便于用户与算法识别「在看什么情绪」。

### 可选基调（包括但不限于）

- **焦虑**：生存、职场、成绩、未来压力
- **愤怒**：不公、欺骗、规则不公、内斗
- **猎奇**：规则漏洞、极限实验、「居然还能这样」
- **震撼**：规模/结果超出预期、认知被颠覆、宏大叙事或极致结局
- **释怀**：从执念/失败/误解中放下，接受、和解或成长
- **恐惧**：危机、失控、未知威胁、失去重要事物的可能
- **优越**：智商/信息/选择上的优越感、「我懂了你还没懂」、爽感
- **共鸣**：被理解、被看见、「说的就是我」、集体情绪共振
- 其他：希望等（若业务需要可补充）

### 及格标准

- 能明确说出本条内容**主打哪一种情绪**；
- 情绪与事件强绑定，非强行煽情。

### 不及格理由

- **基调不明**：「情绪基调不明确，看不出主打情绪（如焦虑、愤怒、猎奇、震撼、释怀、恐惧、优越、共鸣等），用户难以形成稳定预期。」
- **情绪与事件脱节**：「情绪与事件关联弱，像硬贴情绪，容易让用户出戏。」

---

## 六、选题及格判定流程

审校时**先做前置判定，再做五维检查**。任一项判为不及格即整体不及格，并输出理由；全部通过才进入后续优化。

```
步骤 0 - 前置判定
  → 文案是否为 财经/医疗/科技/生物 领域的「专业长分析 + 观点输出」类
  → 若是，则选题直接 pass，输出「前置判定：专业长分析观点类」理由，不进入五维，不进入后续优化，结束

步骤 0.5 - 选题合规检查
  → 对照 [合规要求](references/compliance.md)：道德伦理与低俗色情、价值观与社会风气、未成年人保护、法律与公共安全、感官与视听质量、补充条款（负面不露品牌、不涉及国内大厂/领导人/政事）
  → 命中任一禁止项则选题不及格，输出「选题合规」理由并注明依据条款，不进入五维，不进入后续优化，结束

步骤 0.6 - 业务变量选题检查（按 [business-variables.md](references/business-variables.md)）
  → 若为 **AI 整活类**（主体为网页/界面，如网友集体挑战 AI 边界）：须检查网友形象
  → 网友为**负面找骂形象**（非挑战者/测试者）→ 选题不及格，输出「业务变量选题」理由并注明 `[business-variables.md -> 1.4 AI 整活类选题红线]`，不进入五维，不进入后续优化，结束

步骤 1 - 爆点
  → 无清晰反转/新奇 或 无法一句话概括爆点
  → 不及格，输出「爆点」维度理由，结束

步骤 2 - 受众
  → 既不泛受众，也非可运营垂类（且无大众映射）
  → 不及格，输出「受众」维度理由，结束

步骤 3 - 主体
  → 主体模糊 或 与事件无张力 或 主体冲突无看点
  → 不及格，输出「主体」维度理由，结束

步骤 4 - 事件类型
  → 不符合上述任一事件类型（撕逼/整活/正能量/科技突破/猎奇/焦虑/信息差/嘴替等）或 仅为心情随笔
  → 不及格，输出「事件类型」维度理由，结束

步骤 5 - 情绪基调
  → 主情绪不清 或 情绪与事件不匹配
  → 不及格，输出「情绪基调」维度理由，结束

→ 若步骤 0、0.5、0.6 通过且步骤 1～5 全部通过，则选题判定为「及格」，进入后续优化。
```

## 七、不及格时的输出模板

当选题**不及格**时，按以下格式输出，不进入优化流程：

**情况 A：前置判定直接 pass（专业长分析观点类）**

```markdown
## 选题判定：直接 Pass（不进入五维）

**未通过**：前置判定

**理由**：选题属于 [财经/医疗/科技/生物] 领域专业长分析观点输出类文案，不符合本审校流程的选题范围，直接 pass。

**建议**：此类内容请使用对应领域的专业审校或合规流程；本流程适用于故事化、事件向、可复述名场面的短视频选题。

---
*不进入五维检查及后续优化。*
```

**情况 B：选题合规检查不通过**

```markdown
## 选题判定：不及格（合规）

**未通过**：选题合规检查

**理由**：[具体描述命中的禁止项]，依据 compliance.md 第 X 条 / 补充条款。

**建议**：删除或改写涉规内容后方可进入选题五维检查；若为红线类（如低俗色情、涉毒、违法），建议整体调整选题方向。

---
*不进入五维检查及后续优化。*
```

**情况 B2：业务变量选题检查不通过**

```markdown
## 选题判定：不及格（业务变量选题）

**未通过**：业务变量选题检查

**理由**：AI 整活类（主体为网页）中，网友为负面找骂形象，非挑战者/测试者。依据 `[business-variables.md -> 1.4 AI 整活类选题红线]`。

**建议**：调整网友定位为挑战者/测试者形象，或更换选题方向。

---
*不进入五维检查及后续优化。*
```

**情况 C：五维中任一项不及格**

```markdown
## 选题判定：不及格

**未通过维度**：[爆点 / 受众 / 主体 / 事件类型 / 情绪基调]（可多选）

**理由**：
- [从上方「不及格理由」中选取或微调后的具体说明，按未通过维度逐条列出]

**建议**：
- [针对未通过维度，给出 1～2 条可操作的调整方向，如：补充爆点一句话、明确目标受众、更换主体或事件类型、明确情绪基调]

---
*选题及格后方可进入业务变量注入、结构诊断、行文技巧等后续步骤。*
```

## 八、及格时的输出说明

当选题**及格**时，在审校报告中可简要注明：

```markdown
## 选题判定：及格

- 爆点：[一句话概括]
- 受众：[泛受众 / XX 垂类]
- 主体：[谁]
- 事件类型：[类型]
- 情绪基调：[基调]

进入后续优化流程。
```
