# 产品说明书通用规范

以下为用户已提供的规范。生成时按实际产品与页面适用，不新增不相关功能。缺少定义或与旧规则冲突时，提出一个具体确认问题，确认后记录适用范围。

## 时间与数据

- 时间与日期统一使用东八区（Asia/Shanghai），明确日期边界与统计口径。
- 涉及时间筛选组件时，可选日期必须包含当天。不代表每次查询都强制选中当天，也不代表当日数据已经完整。
- 若确实不能包含当天，须向用户询问业务理由并明确确认，记录页面 / 数据范围、理由、确认人、确认日期及适用版本。不得用自行推断的 T-1 原因替用户批准例外。
- 既有要求有“T-1 数据、默认 T-14～T-1”。分别确认可选日期范围、默认查询范围、数据更新时间 / 完整性及展示提示；默认区间存在歧义时留到当前时间板块确认，不自行改成新的固定区间。
- 环比对比日期不重叠，明确两段长度、边界、时区与数据完整性。
- 数据更新要求：新账号 3 个月、日常 14 天、每周一 2 个月。适用数据源、补采或回刷含义、执行时点、重复数据处理与失败行为按项目确认，不把这三个数字当成所有产品的数据保留期。
- 看板指标明确来源、统计对象、分子分母、过滤条件、周期及更新时点，逻辑自洽且可验收；内部自洽不能代替来源准确性。

## 组件与界面

- 根据已有项目和确认结果从 Element Plus / Ant Design Vue / Vuetify / Vant 4 / Naive UI 中确定组件库，不要求一个项目同时使用全部组件库。
- 图标使用 Remix Icon；业务组件优先查看已有规则并引用其定位，差异明确确认。
- 人名展示飞书中文名，过滤封禁用户。历史数据关联封禁人员如何展示须在适用页面确认，不擅自删除历史记录。
- 业务线、人员筛选支持输入搜索；搜索筛选支持可输入下拉，悬浮框不留空，复杂筛选固定常用条件。具体默认项和无匹配反馈在页面确认。
- 废弃操作需二次确认并填写理由，记录对象、操作者、时间和理由；删除、永久删除等独立业务规则另行确认。
- 视频预览在 100% 缩放下关键内容一屏完整展示，确认验收分辨率与关键内容范围；视频支持全屏播放及一屏完整展示。

## 通知告警

- 飞书通知标题包含功能模块。
- AI 长任务的通知规则须与用户确认，包括触发事件、接收者、内容和重复通知处理；不等同于自动向他人发送真实测试通知。
- 生成失败由机器人告警到线上监控群，明确失败口径、必要定位信息、触发与去重规则；具体机器人和群由项目确认。

## 上线与迭代

- 新功能上线流程增加业务测试环境测试环节，明确验收范围、责任人和通过条件。
- 默认迭代方向为：MVP 跑通核心链路 → 二期解决高频阻断需求 → 三期补充效率看板。按真实需求确认每期范围，不为凑阶段添加看板。
- 正文保持当前有效规则；每次已确认改动记录版本、原因、影响范围、确认结论和验收状态，关联页面与链路同步更新。
