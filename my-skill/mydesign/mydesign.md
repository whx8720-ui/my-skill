# MyDesign 设计规范

版本：1.1 · 2026-10-12 · 智创平台 PC 高保真原型

## 1. 设计目标与适用范围

根据需求说明书和交互规则生成可操作的后台、工作台、数据列表和业务表单。默认 Vue 3 + Element Plus，中文、亮色、模拟数据；主要服务 PC，不默认制作移动端或接入后端。

支持粗浅想法、完整说明书与页面字段思维导图。先按角色梳理交互链路，按页面上下顺序说明核心组件与复用规则，用户确认后才生成产品实现；后续优化先提供独立组件 HTML 预览，确认后合并整页。阶段、确认与版本管理遵循 [确认与迭代工作流](references/workflow.md)。

视觉基准为 `assets/linear-light.html`。补充 Linear 的克制强调色、细边框、清晰文字层级、紧凑操作及表面分层；不继承 Linear 官网的深色背景、超大营销标题和大幅留白。

## 2. 发生冲突时

按职责判断，不简单照抄旧页面：

1. 本次用户明确确认的需求优先；未确认、会改变业务结果的冲突应单问澄清。
2. 业务规则按 [智创交互规则](references/interaction-rules.md)，组件行为按 [组件索引](references/component-catalog.md) 及相关源文件；规则要求可补齐示例缺失的行为。
3. 视觉按本文件及亮色样张；旧组件的颜色、字体、阴影、圆角不覆盖统一主题。
4. Linear 合集只补充与亮色 PC 产品相容的原则。Element Plus 默认外观通过主题调整，不反过来覆盖本规范。
5. 样张中“改前”“别这样”以及多个对比方案不是同时适用的规则。采用改后与明确约定；遇到互相矛盾的示例，以本文件的裁决为准。

## 3. 视觉语言

整体清晰、轻量、紧凑。用白色与浅灰表面、1px 边框区分区域，主要依靠字体、间距与排列建立层级。页面围绕业务对象和操作组织，不默认堆砌指标卡片或装饰图。

### 颜色

以下值来自亮色样张当前 `data-accent="blue"` 模式。默认不展示主题切换器。

| 语义令牌 | 值 | 用途 |
|---|---|---|
| `--md-canvas` | `#fcfcfd` | 页面底色 |
| `--md-surface` | `#ffffff` | 卡片、弹窗、输入区域 |
| `--md-surface-2` | `#f7f8f9` | 表头、悬停、次级区域 |
| `--md-surface-3` | `#f0f1f3` | 更深一层的中性表面 |
| `--md-ink` | `#08090a` | 正文、标题 |
| `--md-ink-muted` | `#6b6f76` | 辅助说明 |
| `--md-ink-subtle` | `#8a8f98` | 非关键元信息、占位 |
| `--md-hairline` | `#e6e7eb` | 普通边框 |
| `--md-hairline-strong` | `#d0d2d8` | 输入和次按钮边框 |
| `--md-primary` | `#0070f3` | 主按钮、链接、选中 |
| `--md-primary-hover` | `#3291ff` | 主色悬停 |
| `--md-primary-focus` | `#0761d1` | 焦点和按下 |
| `--md-primary-tint` | `rgba(0,112,243,.08)` | 浅色选中面 |
| `--md-success` | `#27a644` | 成功 |
| `--md-danger` | `#e5484d` | 错误、危险操作 |
| `--md-warn` | `#d97706` | 等待、风险提醒 |

保留样张色值，不擅自改成 Element Plus 默认蓝或 Linear 紫。辅助灰不能用于关键输入内容或唯一状态提示；状态同时带中文，不能只靠红绿。若具体项目要求严格对比度，应明确记录需要调整的令牌并与用户确认，不能声称样张全部达到可访问性标准。

### 字体与层级

字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", Arial, sans-serif`。不要求下载 Linear 私有字体，不全站使用等宽字体。数字可用 `font-variant-numeric: tabular-nums`。

| 用途 | 字号／字重 | 说明 |
|---|---|---|
| 页面标题 | 28px / 600 | 行高 1.2，字距 -0.6px |
| 大区块标题 | 22px / 500 | 行高 1.25，按页面密度使用 |
| 面板标题 | 15px / 600 | 紧凑列表优先用此层级 |
| 正文、表单 | 14px / 400 | 行高 1.5 |
| 辅助说明、次要操作 | 13px / 400–500 | 次级文字色 |
| 表头、时间、ID、大小 | 12px / 400–600 | 核心数据不能为塞入一屏而无限缩小 |

### 间距、尺寸与边框

- 常用间距：4、8、12、16、24、32px；图标文字可用 6px 等样张已有间距，不机械要求所有尺寸为 4 的倍数。
- 控件圆角 8px，标签 6px，小标记 4px，卡片 12px，大面板／弹窗 16px。
- 普通按钮／输入高度 32px；强调按钮 36px；行内小按钮 28px。不要全局 `size="small"` 导致所有控件缩为 24px。
- 图标 16–17px，图标按钮命中区 32×32px，操作间距 4px。
- 表头约 40px，普通单行数据约 48px；有媒体或多行信息时按内容增高。
- 页面左右留白 24–32px，面板内边距通常 24px，紧凑工具栏可 16px。导航、筛选、表格、分页形成清晰区域。
- 1120px 是样张展示容器，不是所有后台页面的强制宽度。表格页可随可用视口伸展，长表单可限宽。
- 主要使用细边框，菜单可用 `0 4px 16px rgba(8,9,10,.10)` 的轻阴影；不加大面积光晕、渐变、玻璃卡片或持续装饰动画。

## 4. 页面与组件规则

### PC 布局

在 1440×900 与 1366×768、浏览器 100% 缩放检查关键内容：标题、主操作、筛选、核心数据和分页可达。优先合理列宽、信息优先级、折叠次要筛选和表格内部滚动；不强行隐藏字段、缩放整个页面或挤压到不可读。长内容允许滚动，弹层不能超出视口；不依靠全局 `overflow:hidden` 掩盖溢出。

### 按钮和操作

- 每个局部任务区域一个主要提交动作。普通行操作用文字或轻量按钮；业务动作如“校准”“替换素材”必须有文字。
- 通用图标操作提供完整中文 Tooltip 与可访问名称；150ms 左右出现提示，键盘焦点可辨认。
- 稀有危险操作放“更多”菜单并标红；批量危险操作可在工具栏显示红色文字按钮。执行前确认，按业务规则填写理由。
- 一致动作保持相对顺序；主操作靠左，“更多”靠右。
- 提交中显示加载并防重复；禁用说明原因；成功更新对应数据，失败保留用户输入并可重试。

### 筛选与日期

- 人员、业务线、平台使用 `ElSelect filterable`，按需求启用 `clearable`，人名显示飞书中文名。
- 日期使用 `ElDatePicker` 封装；T-1 和默认 14 天仅用于抓取统计，实时历史记录与生成记录允许当天。详细口径见交互规则。
- 筛选应真正改变列表、汇总和分页，重置回该业务场景的默认值；无结果展示可恢复的空态。

### 表格、表单与弹层

- 表格用 `ElTable`，表头浅灰、正文白底、行悬停浅灰；文字左对齐、数字右对齐。长 ID 可截断但支持查看完整值或复制。
- 菜单和 Tooltip 使用 Element Plus 的弹层能力，避免被表格圆角容器裁切；弹层主题用全局令牌或 popper class，不只写在 scoped 容器内。
- 表单用 `ElForm` 和对应输入控件，必填、错误、范围限制有明确反馈。错误定位到字段；取消不提交。
- 废弃／删除弹窗显示操作对象、影响、原因输入和取消／确认。模板默认要求理由，可按后续明确业务要求调整。
- 组件缺少某状态时补齐，不要求每个无关组件机械实现全部状态。

### 文案与动效

- 说明通常一句，放在相关位置；重复等待说明合并；上传格式细节放上传区域或弹窗。
- 不使用“说明：”“注意事项：”堆砌文案；优先说明实际结果和恢复方法。
- 悬停／颜色过渡 120–160ms，弹层以控件库默认轻量过渡为基础；尊重减少动态效果设置。

## 5. 复用与技术实现

使用 [组件索引](references/component-catalog.md) 查找已有行为。维护 `src/components/business/` 中的业务组件，集中配置业务参数；跨页面复用同一实现，不复制多个略有差异的日期筛选器或确认弹窗。

主题由 `assets/vue-starter/src/styles/mydesign.css` 映射到 `--el-*` 变量。先引入 Element Plus CSS，再引入本主题。Element Plus 负责基本控件和键盘行为；图表可使用专用图表库或 SVG，媒体可用原生 audio/video，周边操作仍用 Element Plus。

复用旧示例的交互，不复用其全部样式、固定数据与缺陷。没有真实媒体时标明占位／无可用文件，不用只有按钮变色的效果宣称播放成功。模拟消息记录只留在本地，不实际发送飞书通知。

## 6. 交付验收

按 [工程与验收](references/engineering.md) 检查：能安装、能构建、真正使用 Element Plus，主流程可操作，筛选／状态／统计一致，异常能恢复，日期口径符合场景，取消无副作用，废弃理由生效，视觉遵循亮色样张。记录未实现或未验证项。
