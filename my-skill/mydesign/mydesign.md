# MyDesign 设计规范

版本：1.5 · 2026-10-28 · 智创平台 PC 高保真原型

## 1. 设计目标与适用范围

根据需求说明书和交互规则生成可操作的后台、工作台、数据列表和业务表单。默认 Vue 3 + Element Plus，中文、亮色、模拟数据；主要服务 PC，不默认制作移动端或接入后端。

凡是做产品原型，或修改任何产品 HTML 文件（含已有的单文件演示页），都按本规范执行。新建原型走 Vue 3 + Element Plus；修改已有 HTML 时保留原有技术栈，不顺手迁移框架，但新增或改动的元素在颜色、字号、圆角、图标和提示样式上必须符合本规范与样张。

修改已有 HTML 前，先检查页面主色、按钮层级与提示样式是否符合本规范。用户已长期要求默认主动统一样式：无需反复询问配色，直接在独立候选中统一为紫蓝 #5e6ad2，并简述差异；保留原文件和业务规则，合并仍遵循组件预览确认流程。用户当前明确限制修改范围或指定其他配色时，以当前要求为准。

修改分两级：新增组件或改变视觉布局，先交付组件预览，确认后合并；只改文案、下拉选项、交互逻辑，先列改动清单，确认后直接修改，不出预览。

支持粗浅想法、完整说明书与页面字段思维导图。先按角色梳理交互链路，按页面上下顺序说明核心组件与复用规则，用户确认后才生成产品实现；后续优化先提供独立组件 HTML 预览，确认后合并整页。阶段、确认与版本管理遵循 [确认与迭代工作流](references/workflow.md)。

视觉基准为 `assets/linear-light.html`。补充 Linear 的克制强调色、细边框、清晰文字层级、紧凑操作及表面分层；不继承 Linear 官网的深色背景、超大营销标题和大幅留白。

## 2. 发生冲突时

按职责判断，不简单照抄旧页面：

1. 本次用户明确确认的需求优先；未确认、会改变业务结果的冲突应单问澄清。
2. 业务规则按 [智创交互规则](references/interaction-rules.md)，组件行为按 [组件索引](references/component-catalog.md) 及相关源文件；规则要求可补齐示例缺失的行为。
3. 视觉按本文件及亮色样张；旧组件的颜色、字体、阴影、圆角不覆盖统一主题。
4. Linear 合集只补充与亮色 PC 产品相容的原则。Element Plus 默认外观通过主题调整，不反过来覆盖本规范。
5. 样张中“改前”“别这样”以及多个对比方案不是同时适用的规则。采用改后与明确约定；遇到互相矛盾的示例，以本文件的裁决为准。

## 3. 视觉语言

整体清晰、轻量、紧凑。用白色与浅灰表面、1px 边框区分区域，主要依靠字体、间距与排列建立层级。页面围绕业务对象和操作组织，不默认堆砌指标卡片或装饰图。

### 颜色

用户已于 2026-10-28 明确将紫蓝 `#5e6ad2` 设为长期默认。主色令牌采用亮色样张的紫蓝模式；中性表面与排版仍沿用样张。原始样张保留不改，不再将其 `data-accent="blue"` 视为当前默认。默认不展示主题切换器。

| 语义令牌 | 值 | 用途 |
|---|---|---|
| `--md-canvas` | `#fcfcfd` | 页面底色 |
| `--md-surface` | `#ffffff` | 卡片、弹窗、输入区域 |
| `--md-surface-2` | `#f7f8f9` | 表头、悬停、次级区域 |
| `--md-surface-3` | `#f0f1f3` | 更深一层的中性表面 |
| `--md-ink` | `#08090a` | 正文、标题 |
| `--md-ink-muted` | `#6b6f76` | 辅助说明 |
| `--md-ink-subtle` | `#8a8f98` | 非关键元信息、占位 |
| `--md-hairline` | `#e6e7eb` | 普通边框 |
| `--md-hairline-strong` | `#d0d2d8` | 需要描边的表单输入与区域边界；不用于普通按钮描边 |
| `--md-primary` | `#5e6ad2` | 主按钮、链接、选中 |
| `--md-primary-hover` | `#828fff` | 主色悬停 |
| `--md-primary-focus` | `#5e69d1` | 焦点和按下 |
| `--md-primary-tint` | `rgba(94,106,210,.08)` | 浅色选中面 |
| `--md-success` | `#27a644` | 成功 |
| `--md-danger` | `#e5484d` | 错误、危险操作 |
| `--md-warn` | `#d97706` | 等待、风险提醒 |

采用上述样张紫蓝令牌，不擅自替换为 Element Plus 默认蓝或其他近似紫色。辅助灰不能用于关键输入内容或唯一状态提示；状态同时带中文，不能只靠红绿。若具体项目要求严格对比度，应明确记录需要调整的令牌并与用户确认，不能声称样张全部达到可访问性标准。

### 字体与层级

字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", Arial, sans-serif`。不要求下载 Linear 私有字体，不全站使用等宽字体。数字可用 `font-variant-numeric: tabular-nums`。

| 用途 | 字号／字重 | 说明 |
|---|---|---|
| 页面标题 | 28px / 600 | 行高 1.2，字距 -0.6px |
| 大区块标题 | 22px / 500 | 行高 1.25，按页面密度使用 |
| 面板标题 | 15px / 600 | 紧凑列表优先用此层级 |
| 正文、表单 | 14px / 400 | 行高 1.5 |
| 辅助说明、次要操作 | 13px / 400–500 | 次级文字色 |
| 表头、时间、ID、大小 | 12px / 400–600 | 核心数据不能为塞入一屏而无限缩小 |

相同语义在主页面、预览、弹窗、抽屉和历史卡片中使用同一字号、字重、行高与颜色；面板／管理弹窗标题默认 15px/600，正文与输入值 14px/400（行高 21px），普通按钮与辅助操作 13px/500，时间与元信息 12px。以实际渲染样式核对，移除与语义主题冲突的旧字号工具类；不要将文字烘焙在 SVG／图片里造成字号失控。系统按同一字体栈回退是允许的，不为模仿截图另配字体。

### 间距、尺寸与边框

- 常用间距：4、8、12、16、24、32px；图标文字可用 6px 等样张已有间距，不机械要求所有尺寸为 4 的倍数。
- 控件圆角 8px，标签 6px，小标记 4px，卡片 12px，大面板／弹窗 16px。
- 普通按钮／输入高度 32px；强调按钮 36px；行内小按钮 28px。不要全局 `size="small"` 导致所有控件缩为 24px。
- 图标 16–17px，图标按钮命中区 32×32px，操作间距 4px。
- 表头约 40px，普通单行数据约 48px；有媒体或多行信息时按内容增高。
- 页面左右留白 24–32px，面板内边距通常 24px，紧凑工具栏可 16px。导航、筛选、表格、分页形成清晰区域。
- 1120px 是样张展示容器，不是后台页面宽度上限。工作台、表格和资产网格默认铺满扣除导航、合理内边距后的可用宽高；不固定窄容器居中，不在底部留大块无用空白。长表单／阅读详情可按任务需要限宽。
- 细边框用于区域、卡片及需要描边的表单输入；按钮与图标操作按下节无边框规则。菜单可用 `0 4px 16px rgba(8,9,10,.10)` 的轻阴影；不加大面积光晕、渐变、玻璃卡片或持续装饰动画。

## 4. 页面与组件规则

### PC 布局

在 1920×1080、1440×900 与 1366×768、浏览器 100% 缩放检查。工作台和管理弹窗的内容随可用宽高伸展；标题、筛选、当页数据、警示、分页及底部操作必须同时处于视口内。

- 分页组件固定在所属页面／弹窗内容区的右下角，在独立底栏右对齐；不得居中、随数据漂移，或滚到数据末尾才可见。相对于所属容器布局，不能用相对浏览器的 fixed 把分页脱离弹窗；底栏必须预留高度，不遮挡最后一行。若弹窗另有确认栏，分页放在内容底栏右端，确认栏同样保持可见。
- 分页表格与资产网格的“当页内容必须一屏看完”：先扣除标题、筛选、提示、分页和操作栏高度，再决定可容纳的完整行数／卡片行数和每页数量。不能保留过大的每页数量，再让用户在本页内部上下滚动才能看全；窗口变化后重算可容纳数量、页码与数据范围，确保无遗漏／重复。
- 网格列数和列宽响应可用空间；分页总数、当前页、已选数量与真实数据保持一致，跨页选择不丢失。数据不足一页时底栏仍固定，空态亦不改变底栏位置。
- 不通过缩放页面、缩小规范字号、裁切内容、隐藏必要字段或全局 overflow:hidden 达成一屏。确需长文本编辑或阅读的非分页详情，可仅在内容区滚动；该例外不覆盖分页表格和资产网格。弹窗始终不超视口。

### 按钮和操作

- 默认所有按钮均无可见描边，包括文字按钮、图标按钮、关闭、置顶、更多、取消、下载、增强及分页操作。普通／次要操作默认透明底、无边框、无边框阴影；禁止通过 inset box-shadow 伪造边框。主提交可保留紫蓝实心底；危险确认只在确认弹窗可用危险色实心底，均无描边。
- 图标按钮默认只显示图标，不常驻圆形／方形底框；悬停可用浅灰底或规定强调色，按下／选中可用主题浅色底，禁用用弱化色；保留键盘 focus-visible 焦点环。图标本身的 SVG 线条不属于按钮边框，不要移除图形。图片悬停删除的承托底按场景处理。
- 图标默认 16–17px、点击区域 32×32px；带文字图标间距通常 6px。同一动作在预览、历史、弹窗及管理界面复用同一图标定义、尺寸和线宽，不各画一套、不用 emoji 或文字字符冒充。
- 模型和时长等行内参数控件同样无边框、无边框阴影，悬停用浅灰底，键盘焦点可辨认；不可只移除外层 border 而遗留控件 wrapper 的阴影。此要求不默认移除搜索／理由输入等所有表单边框。
- 每个局部任务区域一个主要提交动作。普通行操作用文字或轻量按钮；业务动作如“校准”“替换素材”必须有文字。
- 通用图标操作提供完整中文 Tooltip 与可访问名称；150ms 左右出现提示，键盘焦点可辨认。
- 稀有危险操作放“更多”菜单并标红；批量危险操作可在工具栏显示红色文字按钮。确认与理由按业务影响决定，见交互规则；生视频项目移除参考图的悬停 × 是明确例外，直接移除引用，不弹理由框。
- 一致动作保持相对顺序；主操作靠左，“更多”靠右。
- 提交中显示加载并防重复；禁用说明原因；成功更新对应数据，失败保留用户输入并可重试。

### 筛选与日期

- 人员、业务线、平台使用 `ElSelect filterable`，按需求启用 `clearable`，人名显示飞书中文名。
- 日期使用 `ElDatePicker` 封装；T-1 和默认 14 天仅用于抓取统计，实时历史记录与生成记录允许当天。详细口径见交互规则。
- 筛选应真正改变列表、汇总和分页，重置回该业务场景的默认值；无结果展示可恢复的空态。

### 表格、表单与弹层

- 表格用 `ElTable`，表头浅灰、正文白底、行悬停浅灰；文字左对齐、数字右对齐。长 ID 可截断但支持查看完整值或复制。
- 菜单和 Tooltip 使用 Element Plus 的弹层能力，避免被表格圆角容器裁切；弹层主题用全局令牌或 popper class，不只写在 scoped 容器内。
- 表单用 `ElForm` 和对应输入控件，必填、错误、范围限制有明确反馈。错误定位到字段；取消不提交。
- 需要废弃／删除确认时显示操作对象、影响、原因输入和取消／确认。模板默认要求理由，但不得把它套用到明确无需确认的移除引用等场景；生视频的资产删除与分卷关闭见 [场景规则](references/video-generation.md)。
- 管理弹窗复用所属业务的分类、搜索、选择、置顶、分页及确认结构，外观按本规范统一，不直接照抄截图中的旧字体、默认蓝色、居中分页或黄色整条底色。
- 组件缺少某状态时补齐，不要求每个无关组件机械实现全部状态。

### 文案与动效

- 新增界面元素先在样张里找对应组件，按其样式实现，不自配近似色。提示分级：说明用 muted `#6b6f76` 13px 纯文字；警示用样张「一句说明 + 一条警示」的 `.note.is-warn`，文字与三角图标 `#d97706`，底色 `rgba(217,119,6,.06)`，边框 `rgba(217,119,6,.2)`，8px 圆角；红色 `#e5484d` 只用于删除等危险动作。
- 说明通常一句，放在相关位置；重复等待说明合并；上传格式细节放上传区域或弹窗。数量达到上限的行内提醒使用 --md-warn（#d97706）13px 纯文字，仅条件满足时出现，未达到不占提示位置；不机械包成整条警示面板。具体阈值和文案由模型／业务配置决定。
- 不使用“说明：”“注意事项：”堆砌文案；优先说明实际结果和恢复方法。
- 悬停／颜色过渡 120–160ms，弹层以控件库默认轻量过渡为基础；尊重减少动态效果设置。

### 交互规则变更

用户修改某条交互规则时，动手前先列出与之关联的规则：同一对象的数量限制、互斥、命名、按钮状态、提示文案、按钮可用性，以及写入提示词或其他页面的文本。逐条说明是否需要一起改、不改会出现什么问题，等用户确认后再改；未确认的关联项不动。

示例：把「参考视频和故事板二选一」改为可以共存，需要一起确认：提示词首句是否两句并存、互斥警示是否移除、「生成故事板」是否不再禁用、资产按钮状态如何显示。

## 5. 复用与技术实现

使用 [组件索引](references/component-catalog.md) 查找已有行为。维护 `src/components/business/` 中的业务组件，集中配置业务参数；跨页面复用同一实现，不复制多个略有差异的日期筛选器或确认弹窗。

主题由 `assets/vue-starter/src/styles/mydesign.css` 映射到 `--el-*` 变量。先引入 Element Plus CSS，再引入本主题。Element Plus 负责基本控件和键盘行为；图表可使用专用图表库或 SVG，媒体可用原生 audio/video，周边操作仍用 Element Plus。

复用旧示例的交互，不复用其全部样式、固定数据与缺陷。没有真实媒体时标明占位／无可用文件，不用只有按钮变色的效果宣称播放成功。模拟消息记录只留在本地，不实际发送飞书通知。

## 6. 交付验收

验收必须实际核对无边框按钮／图标、模型与时长 wrapper、跨容器图标一致性、语义字号、内容铺满和右下角固定分页；分页场景的当页数据必须一屏看完，不能只证明“分页可达”。

按 [工程与验收](references/engineering.md) 检查：能安装、能构建、真正使用 Element Plus，主流程可操作，筛选／状态／统计一致，异常能恢复，日期口径符合场景，取消无副作用，废弃理由生效，视觉遵循亮色样张。记录未实现或未验证项。
