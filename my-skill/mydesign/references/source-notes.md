## 已发现的冲突

- 样张默认蓝色，原 Linear 分析为紫蓝色；采用用户样张当前默认蓝色。
- 样张图标原则要求危险操作放更多菜单，某些表格示例又露出删除；采用较明确的原则，批量删除可放工具栏。
- 原设计规则列多种组件库；用户指定 Vue 3 + Element Plus，因此仅保留这一套基础控件库。
- 原确认弹窗无理由字段；原标准要求废弃理由，检查清单要求废弃／删除理由，因此补齐。
- 原规范“环比计算”的文字有歧义、RPI 没有公式；按交互规则说明常规解释和待确认边界，不编造指标。
- 已有 kedoutube-video-gen-design 的单色字体、默认蓝色与其他项目令牌未继承；用户选定的是智创交互规则与 Linear 亮色样张。

## 扩展约定

新增组件先记录业务适用范围、来源和行为，再决定是否进入通用库。用户本次确认的例外只能修改对应场景，不隐式改变所有未来原型。新版需求若与旧规则冲突，保留旧规则适用范围并注明覆盖关系。

## 1.1 工作流补充（2026-10-12）

根据用户补充，输入支持想法、完整 PRD 与页面字段思维导图。产品实现前先整理角色链路和从上到下的页面组件说明，用户确认后再生成；后续变更先输出独立组件 HTML，用户确认后再合并整页。具体约定、版本与范围边界见 workflow.md，不由通用的“主动完成”偏好跳过用户设置的检查点。

用户给出的管理员建产品、传素材、打标删除，以及普通用户输入文案、生成、校准、下载，仅作为本技能的表达案例；不自动成为每个新项目的业务需求。
