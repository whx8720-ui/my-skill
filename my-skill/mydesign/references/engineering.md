# 工程与验收

## 起步

仅在用户确认链路与页面方案后，复制 `assets/vue-starter/`，保留主题与业务组件，替换示例 App 和模拟数据。依赖安装使用 npm，已有项目沿用其包管理器和锁文件，不能同时生成多个锁。后续候选组件在隔离副本内构建，用户确认前不改主工程；见 [工作流](workflow.md)。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

模板用 Node 22.12+（或兼容版本），Vue 3 + Vite + Element Plus；版本以 package.json 与 package-lock.json 为准。标准构建输出 dist，默认通过 HTTP 服务打开。工程是可维护源码，HTML 是给用户查看的入口，两者都要交付，不用它们互相替代。

## HTML 交付与组件预览

- 用户说“生成 HTML”时，保持已确认的 Vue 3 + Element Plus 架构：提供完整页面 HTML 入口和资源，以及 Vue 源工程。不能只交 `.vue`，也不能将框架换成原生模拟控件。
- 组件候选放在隔离目录，使用独立入口挂载候选组件和必要父容器；通过相同主题、Element Plus、模拟数据完成预览。不要为了预览改动主工程的组件、依赖或构建配置。
- 命名采用 `页面名-组件名-v2.html` 等可识别名称，入口与 JS/CSS/字体资源一起打包。标准 Vite 输出需 HTTP 服务，提供已验证地址或清晰启动方式，不声称一个依赖旁边 assets 的 HTML 可脱离资源双击运行。
- 用户需要直接双击单文件时，可将同一 Vue 入口构建为自包含 HTML（例如选用兼容当前 Vite 的内联资源工具）；真实依赖仍来自 Element Plus。必须检查 JS、CSS、字体、媒体与动态导入是否实际内联或有可用来源，验证 file 模式后才声称离线可用。未经验证不承诺单文件运行。
- 组件预览交付带最少的测试上下文和可切换模拟状态；页面标题可说明预览用途，但业务组件内不嵌入技术或合并说明。
- 合并以批准的候选 Vue 源码为准，集成父级 props／events／store／路由变化后重新构建整页 HTML。候选预览和主页面不能维护两套独立实现。

在 `main.js` 实际注册 Element Plus、加载中文 locale 和样式；`mydesign.css` 在组件库 CSS 之后加载。图标使用 Remix Icon，不混搭多套风格。弹层可能 teleport 到 body，主题变量在 :root，弹层专项样式放全局。

需要查询 API 时使用官方文档，并针对安装版本检查：
- [Element Plus 接入](https://element-plus.org/en-US/guide/quickstart.html)
- [主题变量](https://element-plus.org/en-US/guide/theming.html)
- [日期选择器](https://element-plus.org/en-US/component/date-picker.html)
- [Dialog](https://element-plus.org/en-US/component/dialog.html)

## 模拟数据

把数据源集中在 mock 模块或可追踪的 Vue 状态中，日期、人员、列表和统计一致。请求用本地 Promise 模拟，至少为当前需求涉及的加载、失败重试、空数据、禁用与正常情况提供可复现方式。

演示控制可放仅开发使用的“演示状态”入口，不能把组件库版本、技术参数或测试说明当作业务流程。默认无跨刷新持久化，若需要 localStorage，明确键名、重置方式和业务意义。

## 验收清单

- 阶段：实现范围与确认的方案一致；候选预览版本对应确认记录；未确认候选没有进入主工程。
- 依赖：安装成功；package.json 含 vue/element-plus；页面渲染真实 ElButton、ElSelect、ElTable 等；不能仅 import 不使用。
- 构建：执行 npm run build；若受环境限制，记录失败原因，不声称通过。
- 时间：东八区跨日、默认 14 天、T-1 禁止当天、records 允许当天、重置与环比不重叠。
- 操作：取消不改数据、空白理由不通过、二次确认成功后数据变化、提交防重复、失败可恢复。
- 列表：筛选生效、筛选后页码归位、分页总数一致、空态可清除筛选恢复、封禁用户排除。
- 外观：默认蓝色 #0070f3，浅灰底、白面板、8px 控件圆角；组件弹层同样应用主题。
- 浏览器：有权限与工具时检查 1440×900、1366×768 的表格、菜单、弹窗和键盘焦点。构建通过不等于视觉验收。
- 复用组件：批量输入检查 Enter/Shift+Enter/输入法；替换素材检查时长/数量/取消；音视频检查真实播放或明确占位；图表检查口径/导出。

## 模板边界

模板展示素材列表、日期筛选、负责人筛选、详情、废弃理由和四种演示数据状态。它不是具体产品需求，不含真实媒体、通知、鉴权或后端。仅时间筛选与带理由确认提供已实现的业务组件，其余六份 HTML 按实际页面需要迁移。
