# 组件复用索引

所有原始 HTML 位于 `../assets/legacy-components/`，原样保留。这些是行为和外观证据，不是已迁移完毕的 Vue 组件。仅按当前需求读取相关文件，基于 Element Plus 封装；视觉统一参考 `../mydesign.md`。

遇到同类功能（二次确认弹窗、堆积柱线图、批量输入框、替换素材、视频片段、音效样式），必须复用下列对应组件的结构和交互，只替换业务数据，不另写近似组件。修改已有 HTML 时按该页面技术栈复用对应 HTML 的结构与交互，外观按 `../mydesign.md` 统一；Vue 工程按下文迁移说明封装。

首次页面方案中，每个核心组件注明命中的来源及主要规则；本项目已有已确认组件优先。后续修改遵循 [组件预览与合并](workflow.md#6-组件修改与独立预览)，先定位页面，再在候选中修改，用户确认后才合并。禁止直接修改共享组件而让未确认的变化进入其他页面。

## 六个用户组件

### 1. 二次确认弹窗.html

- 已有：居中弹层、标题、危险提示、取消／确认删除。
- 源文件是静态样式，没有实际交互、理由字段。不能视为完整确认流程。
- 仅在业务需要理由确认时使用 `ReasonConfirmDialog`（ElDialog + ElForm + ElInput + ElButton），补齐理由、取消、提交中、失败和关闭恢复。危险确认使用红色主按钮仅限该弹窗，所有按钮均无描边。生视频参考图移除引用不调用该组件；未下载关闭分卷才调用，见 [场景规则](video-generation.md)。

### 2. 批量输出框.html

- 尽管文件名为“输出”，实际是批量视频链接输入：初始一条；Enter 到下一条，末尾新增；Shift+Enter 条内换行；空白行 Enter 提示先输入；焦点只强调当前条；提交 trim 后过滤空项，至少一条。
- 迁移为 ElInput textarea 列表和 ElButton，稳定条目 ID；使用 nextTick 定位新增行；中文输入法 `isComposing` 时不能误触发新增。
- 当前示例只显示提交数量提示。产品原型应生成对应模拟任务或结果，重复提交防护、非法链接提示按需求补齐。
- 平台支持范围与数量上限由需求决定，不从提示文案推断所有项目都接入抖音/TikTok/Bilibili。

### 3. 替换素材0917.html

- 已有：弹窗选中／取消片段、累计已选时长、数量上限、未满足时长时禁用确认；复制哈希不触发选中；溢出描述悬浮查看；取消／Esc 关闭。
- 示例参数：目标时长 10s、最多 3 个、总时长必须等于目标。相同业务可沿用，换业务时参数化并标注默认来源；不升格为平台通则。
- 迁移：ElDialog、ElCheckbox/ElButton、ElTooltip；状态保存在临时选择中，确认才提交到父级，取消恢复原选择。时长用整数毫秒比较，避免浮点误差。
- 源文件确认仅 toast 后关闭，未真正替换；原型需把选择结果回写目标模拟记录。预览、无候选、超限和提交错误按需求补齐。
- 用于资产库管理时只复用临时选择／确认回写契约，不继承示例的时长相等或最多 3 个限制。管理弹窗读取 [生视频与资产管理](video-generation.md)；网格铺满可用区域，分页固定内容区右下角，每页数量依可用高度安排，所有当页卡片完整一屏可见。

### 4. 视频片段.html

- 已有：片段卡片、文案、哈希复制、匹配程度。示例 `score > 60` 为良好，否则较差；这是示例阈值，应配置化。
- 迁移：ElCard/轻布局 + ElTag + ElTooltip + ElButton；媒体用 video controls，支持全屏、正确宽高比和错误态。
- 原脚本只处理评分样式及复制反馈，不证明视频能播放。没有实际视频资产时明确占位，不能把假播放当已完成。

### 5. 音效样式.html

- 已有：按名称搜索、无结果提示、收藏／取消收藏、常用优先、同一时间只有一个试听按钮处于活动状态。
- 迁移：ElInput、ElButton、ElTag；保存初始排序索引，关闭常用优先后恢复基础顺序（源示例不恢复，需修正）。
- 原示例试听只改变按钮，不播放音频。需要实际 audio 源或明确无音频状态；播放失败和 ended 清理状态。

### 6. 堆积柱线图.html

- 已有：可搜索账号选择、按账号过滤堆积柱、折线、双轴、Tooltip、导出 PNG。
- 迁移：账号选择用 ElSelect filterable，导出用 ElButton；图表可保留 SVG 或用专用图表库。图表不是 Element Plus 提供的组件。
- 源示例折线使用固定 publishLine，筛选只影响柱；总标签和轴也有样例常量。必须确认折线是全局还是随筛选变化，清楚标注其范围；不能悄悄输出与统计口径不一致的图。
- 派生总量、动态轴和平均值来自同一份模拟数据，除零处理、Tooltip 越界、空态、导出失败都需要检查。若需求要求截图导出，验证所得文件，不能仅 toast。
