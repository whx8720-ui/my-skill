# 智创平台设计标准参考

> 本文件基于《智创平台产品设计要求汇总》整理，作为交互评审时的细节检查依据。评审时按需查阅，无需每次全量加载。

## 一、技术基础规范

### 组件库
前端组件从以下官方库选用，避免自定义重复造轮子：
- Element Plus、Ant Design Vue、Vuetify、Vant 4、Naive UI

### 图标库
统一使用 Remix Icon（https://remixicon.com/）

### 时区
系统必须使用东8区时区，不得使用其他时区。

## 二、数据规范

### 数据更新策略
| 场景 | 刷新范围 |
|---|---|
| 新账号绑定 | 默认刷新近 3 个月数据消息 |
| 日常每日更新 | 只刷新近 14 天内的数据消息 |
| 每周一定时刷新 | 跑近 2 个月的数据 |

### 时间筛选规则
- 数据时效：数据只能拿到前一天的数据（T-1）
- 环比计算：（本周起 - 上一周期）/ 上周期，日期不重叠
- RPI：相对指标
- 数据抓取类默认范围：T-14 ~ T-1
- 例外：需要看当天的场景不要动（如历史记录、生成等）

### 数据看板
涉及数据的看板，数据内部逻辑必须自洽且能验收。

### 人名展示
- 涉及人名必须使用飞书中文名称，不能是用户名称（拼音缩写）
- 必须过滤封禁用户

## 三、界面与交互设计

### 一屏看完
100% 缩放下，页面关键内容应一屏看完，避免出现展示不完全的情况。表格列数和内容密度需合理控制。

### 搜索与筛选
- 基础搜索+筛选框：涉及人员、业务线、平台的搜索和筛选，统一使用可输入下拉方式
- 悬浮框：不要留空，需有实际内容或合理占位
- 复杂/多条件筛选（参考，非必要）：采用自定义指标配置筛选条件；固定常用筛选条件（平台、人员）

### 废弃操作
废弃功能需要二次确认弹窗，且必须填写理由。

### 视频播放组件
视频播放组件需支持全屏播放，确保一屏内能完整查看。

## 四、通知与告警

### 飞书通知
- 通知标题必须包含功能模块名称
- 凡是接入 AI、等待时间较长、需要用户及时确认的任务，都需要发飞书通知确认

### 异常告警
生成失败时，自动发送机器人告警到线上监控群。

## 五、产品上线流程

| 流程类型 | 步骤 |
|---|---|
| 传统流程 | 调研需求/设计方案原型 → 开发自测 → 产品测试 → 龙龙老师部署 → 发公告 → 正式环境测试 |
| 新功能流程 | 调研需求/设计方案原型 → 开发自测 → 产品测试 → 业务测试环境测试 → 龙龙老师部署 → 发公告 → 正式环境测试 |

## 六、产品迭代节奏
1. MVP：只解决最核心的需求，跑通链路
2. 二期迭代：解决业务使用中高频出现、阻断交互的需求
3. 三期及以后：补充效率看板等辅助产品优化决策
